# Visual references of games

Every game mechanic goes through the same order:

1. We fix the mechanics and the key gesture.
2. We generate a separate full-screen reference.
3. We approve the composition, character, palette and conditions.
4. We describe movement and feedback.
5. Only after this do we transfer the screen into code.

General system constants:

- light and airy food casing;
- graphite body text;
- turquoise interaction color;
- green is the color of correct action;
- coral color bug;
- corgi is an assistant inside the mechanics, not a decorative sticker;
- themed worlds do not change the readability of cards and navigation;
- large game objects instead of small administrative grids.

The current implementation is not considered a visual reference until a reference is approved for the game in its folder.
