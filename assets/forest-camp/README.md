# Forest camp assets

Embedded ImageGen, October 7, 2026. Copies saved in project; Roblox assets are not used.

- `distant-forest-v1.png`: layered evergreen pines, misty hills, pale blue sky, calm stylized low-poly forest; no foreground props, avatars, UI or text. In the game `public/game-assets/forest-camp/distant-forest.webp`.
- `moss-ground-v1.png`: seamless overhead albedo of moss-green grass and muted olive earth, flat lighting, clover and small debris; no objects, shadows or text. In the game `public/game-assets/forest-camp/moss-ground.webp`, 1024 × 1024.
- `docs/games/forest-camp/concept-v1.png`: full 1536×1024 light educational game UI; exact Russian question/answers, three crates, campfire, shared avatar, arrow/E controls. Colors and layout in `VISUAL_BRIEF.md`.

Character - General GLB approved. Game objects and lights are a real Three.js scene, which is intentionally different from the bitmap concept. The background and soil are generated textures. For the current draft, the game's learning loop is more important than the finished graphics.
