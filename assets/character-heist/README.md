## Brief description of prompts

Concept: full primary Russian educational 3D game screen titled “Character Hunt”. Adapt Steal a Brainrot: central moving character market, mint player base foreground, two rival bases with laser locks and guard. Reference `three-skins-v5.png` only locks approved turquoise hoodie identity and proportions. Bright daylight, pale sky, cream architecture, emerald safe area, violet rare accent. White Onest UI, title, subject, avatar, pause. Mission “Buy the first one. Take the rare ones. Gather a team." Quiz appears only on purchase/lock. Team 0/3, coins 20, start button, WASD/E. Original fox astronaut, cat in coffee cup, dragon with headphones. Working draft, no editor or extra systems. Image is design reference, not background.

Sprites: transparent production sprite atlas, exactly three equal isolated square cells in a horizontal row with wide margins. Orange fox astronaut in white/orange suit, complete tail and feet; cream cat in coffee cup with bean emblem and handle; violet tiny dragon wearing teal headphones, complete wings/tail/feet. Polished stylized 3D toy renders, original characters, matching front three-quarter view and soft daylight. No text, prices, platforms, environment or frames; preserve real alpha.
