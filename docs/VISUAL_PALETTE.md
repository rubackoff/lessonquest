# Interface and game palette

This palette captures the approved direction from two “Couples” references:

- `docs/games/match-pairs/editor-media-slots-v1.png` — calm working interface;
- `docs/games/match-pairs/mockup-desktop-v3.png` — a rich game world.

## Operating interface

| Role | Color | Usage |
| --- | --- | --- |
| Canvas | `#F5F7F8` | editor and library background |
| Panel | `#FFFFFF` | sidebars, forms, preview |
| Body text | `#18212D` | titles and content |
| Secondary text | `#647383` | tooltips and metadata |
| Border | `#D5DDE4` | quiet dividers and margins |
| Turquoise | `#138B8F` | selected template, drag, focus, add |
| Green | `#15945B` | retention, validity, readiness |
| Error | `#E84D55` | removal and validation errors |

In the working interface, color occupies a small area. Turquoise indicates a current action or choice, green indicates a confirmed result. They don't replace each other.

## Game world "Underwater World"

| Role | Color | Usage |
| --- | --- | --- |
| HUD | `#06394A` | top gaming panel |
| Deep background | `#074A5D` | blackout over background illustration |
| Card | `#FBFAF6` | game cards |
| Card text | `#073247` | signatures, formulas and answers |
| Active communication | `#39BFAE` | line during selection and drag |
| Correct | `#4EB482` | confirmed connection and check mark |
| Error | `#F08A78` | incorrect connection; not normally used |

## Rules

1. In one condition, one accent is dominant.
2. Green means only a successful or saved state.
3. Coral appears only when there is an error.
4. Blue is not used as an occasional replacement for turquoise.
5. The decorative background does not change the color of the cards and text: the content remains milky and dark sea in all worlds.
